# 🌐 Hiddify 基础使用教程

### 1. 获取应用
* **Hiddify 官方 Github 下载地址**：[点击前往下载 (需科学上网)](https://github.com/hiddify/hiddify-next/blob/main/README_cn.md)

>你也可以选择其他应用，这里主要讲Hiddfy的使用方法，别的软件也差不多一样，导入链接>系统代理>应用全局

* **Clash 官方 Github 下载地址**：[点击前往下载 (需科学上网)](https://github.com/clashbk/clash)

---

### 2. 安装流程
下载安装包后打开，按下图勾选，然后点击 **Next**

![勾选组件](/public/vpn/pc1.png)

接着点击 **Install** 进行安装

![点击安装](/public/vpn/pc2.png)

最后点击 **Finish** 完成安装并启动

![完成安装](/public/vpn/pc3.png)

---

### 3. 基础设置与导入订阅

#### 第一步：初始化设置
进入软件后，语言可以选择 **中文**。
地区选择 **中国** 或其他，然后点击 **开始**

![初始化设置](/public/vpn/pc4.png)

#### 第二步：获取并复制订阅
去联系 **卢老爷** 获取你的专用订阅链接，并将其 **复制** 到剪贴板

#### 第三步：导入配置文件
回到软件主界面，点击下方的 **“新的配置文件”**

![点击新配置文件](/public/vpn/pc5.png)

在弹出的选项中，选择 **“从剪贴板导入”**

![从剪贴板导入](/public/vpn/pc6.png)

#### 第四步：开启科学上网
导入成功后，点击中间的大圆圈按钮 **“点击连接”**

![点击连接](/public/vpn/pc7.png)

此时已经科学上网成功！你可以在 **代理** 选项卡中自由选择你想要的节点

![节点选择](/public/vpn/pc8.png)

---

### 💡 LBW SIR 提示
* **连接失败？** 请检查你的 VPN/加速器是否已开启全局模式，或者尝试更换节点。
