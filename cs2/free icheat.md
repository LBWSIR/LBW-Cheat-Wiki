# 🧊 iCheat 使用教程

欢迎使用 iCheat。请严格按照以下流程进行下载与安装。

::: warning 🛡️ 安全提示
**这不是病毒文件！**
作弊产品需要调用系统高权限内存进行读写，因此防护软件会误报。运行前请务必**关闭所有杀毒软件**或将其加入白名单。
P.S：报错是正常！！！
:::

---

### 📥 获取与安装
1. **访问官网：** 前往 [icheat.io](https://icheat.io/free-cs2-cheats/) 获取最新 Pin 码并下载注入器。
2. **解压文件：** 下载 `DOWNLOAD.zip` 后解压，找到 `undetek-v??.??.exe`。
3. **管理员运行：** 右键点击程序，选择 **[以管理员身份运行]**。
4. **注入启动：** 进入游戏大厅后，输入你获取的 Pin 码即可完成注入。
5. **菜单开关：** 按下键盘上的 **`Del`** 键可开启/隐藏菜单。

### ⌨️ 按键绑定技巧 (重要)
绑定按键时请遵循以下步骤：
1. 先 **按住** 小键盘上的方向键 **`→`**。
2. 同时 **按下** 你想要绑定的目标按键。
> *注意：绑定后显示的是该按键对应的独立数字编码，这是正常现象。*

### 📖 功能与开关翻译

| 英文选项 | 中文含义 | 详细说明 |
| :--- | :--- | :--- |
| **Aimbot** | 瞄准开关 | 自动瞄准总开关 |
| **Key** | 自瞄按键 | 设置自瞄触发键 |
| **Smooth** | 自瞄平滑度 | 数值越低，拉枪速度越快 |
| **Trigger** | 自动扳机 | 准星对准敌人时自动开火 |
| **Spotted** | 可视侦测 | 开启后，仅对视野内敌人生效 (防隔墙) |
| **Esp** | 透视功能 | 墙后敌人位置显示 |
| **Beefmode** | 恶搞模式 | 在角色头上显示恶搞图片 |

**状态显示：**
* <span style="color: #4CAF50; font-weight: bold;">On (绿色)</span>：功能已开启
* <span style="color: #F44336; font-weight: bold;">Off (红色)</span>：功能已关闭
