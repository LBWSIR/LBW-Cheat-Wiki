# Midnight 使用教程

## 注册

**首先进入午夜注册官网 -> [https://midnight.im/join/93611](https://midnight.im/join/93611/) -> 右上角 Register（注册），如果已有账号点击 Log In 登陆即可。**

**注册时在弹出的窗口中 -> 依次输入：用户名 / 邮箱 / 密码 / 完成人机验证 / 勾选协议 -> 点击 Register 完成注册。**

## 续费购买 & 激活卡密

**续费就找卢姥爷，包你良好服务体验**

1. 您可以通过 [https://midnight.im/usercp/](https://midnight.im/usercp/) 或者导航栏中的 User CP 进入 Subscriptions 页面。
2. 页面中右上角单击 **ACTIVATE KEY（激活秘钥）** -> 在弹出的窗口中输入您购买的午夜秘钥 -> **ACTIVATE KEY** 即可激活完毕。

提示：您可以在此页面查看 HACK 过期时间。

## 下载客户端

请通过论坛导航栏（论坛首页左上角）-> **DOWNLOAD LOADER（下载客户端）** -> 在弹出的页面中 -> **DOWNLOAD** 即可下载客户端。

## 注入

**注意**：注入前请先关闭你电脑中的全部杀毒软件（建议卸载火绒除外）和微软防火墙。读条长时间不动请挂梯子或者加速器。

**右键管理员身份运行午夜客户端文件**（此步骤给予客户端可以注入进程相关权限避免无法注入）

![登录界面](/images/cs2/midnight_e45a4b16782a81e0b1714ece40c4c3c.png)

输入您官网的邮箱与密码 -> 单击 **LOG IN NOW（现在登陆）** -> 此时会转圈加载然后查阅下一步

**选择 CSGO 版本 -> START IT NOW（开始注入）** / 本次选择 Beta 版注入游戏

![注入选择](/images/cs2/midnight_d7549bec2c0db7241d4aa2426bf8ff5.png)

单击完毕后 -> 等待下载午夜客户端资源 -> 开始转圈等待。（可能中途会弹 CMD 窗口无视即可）

注入过程中 -> 绿色进度条 -> 加载完毕会自动打开 Steam 平台 -> 弹窗告知您可以运行 CSGO 客户端

最后运行 CSGO 游戏客户端进入大厅自动注入完毕 -> 菜单自动呼出（INS 显示隐藏）-> 享受游戏。
