# Meow 常见问题

使用 `Meow` 中常见的一些问题解答

在解决问题之前，请先保证自己已经做了以下准备：

> 杀毒已经完全关闭
> 以管理员身份运行

## 常见问题

### 卡死/无响应

![卡死](/images/mingchao/+E5+8D+A1+E6+AD+BB-40f223861db167dedfa144a98328b3a8.png)

1. 尝试重启游戏和注入器
2. 关闭不必要的后台程序
3. 以管理员身份重新运行

### 注入器客户端连接失败

![连接失败](/images/mingchao/+E6+B3+A8+E5+85+A5+E5+99+A8+E5+AE+A2+E6+88+B7+E7+AB+AF-2bbb2967dbfc4587f9b4662fddaf63ac.png)

1. 关闭梯子/VPN 后尝试
2. 或者开启梯子/VPN 后尝试
3. 检查网络连接是否正常
4. 关闭所有杀毒软件后重试
