# Akebi 报错与错误提示

**主要处理 Akebi 启动时遇到的问题，若 Akebi 成功载入并打开 GUI 后遇到一些问题**

在解决问题之前，请先保证自己已经做了以下准备：

> 杀毒已经完全关闭
> 以管理员身份运行
> 游戏已更新到最新版本

## 常见报错及解决方法

### 1. "Failed to initialize"
- 尝试重新下载并解压注入器
- 确保路径没有中文
- 关闭所有杀毒软件

### 2. "Driver not loaded"
- 以管理员身份重新运行
- 重启电脑后再次尝试
- 检查系统是否为 Windows 10 或 Windows 11

### 3. "Game not found"
- 确保原神游戏已经启动
- 检查游戏窗口模式是否为无边框窗口
- 尝试使用官方启动器修复游戏文件

### 4. 注入器闪退
- 关闭所有杀毒和防护软件
- 检查 .NET 运行库是否安装完整
- 尝试兼容模式运行（Windows 8）
